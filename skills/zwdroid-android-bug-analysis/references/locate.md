# locate.md — S2 窗口定位

目标:在海量日志里圈出"哪个进程在什么时间发生了什么行为导致什么结果"的**有效关键信息**,
交给 S3。核心纪律:**先收敛搜索空间(廉价结构过滤),再烧语义预算**;双通道防确认偏误。

## 决策图(细节以「步骤细则」为准)
```
查 manifest 两步定位锚点(细则 1)
        │
   r=1: batch = 锚点文件 ±2(细则 2)
        │
   ┌────┴────┐
通道一 preset 切片   通道二 scream-scan   (并列不合并 R10,细则 3/4)
   └────┬────┘
        ▼
   锚点 sanity check,三态(细则 5)
   ├─ 三对齐命中 → 语义匹配(细则 6)
   ├─ 部分命中   → 锚点校正 → 重定位
   └─ 完全无特征 → 策略切换 或 中断问用户
        ▼
   语义匹配到有效关键信息?
   ├─ 是 → explore 精定位(细则 8)→ S3
   └─ 否 → 二次 grep(细则 6)→ 仍无 → 扩展判定(细则 7):
           达上限/穷尽 → S6b;slow → 采样;否则 r+=1 回双通道
```

## 步骤细则

1. **两步定位锚点**:`rca-ingest.py` 若未跑先跑。查 `manifest/sessions.tsv` 定 anchor_time 所属
   session(注意 `clock-*.tsv` 跳变点),再查 `files.tsv` 定所在文件——**一律用 manifest 的
   time_span,勿信文件名 `@时间`(见「已知坑」)**。落在文件边界则两文件都算锚点。
2. **batch_1** = 锚点 ±2 文件(共 5)。用 `log-batch.py <锚点> 2 --manifest <dir>` 产出,它保证不跨 session。
3. **通道一**:`logcat-window.py <start> <dur> --preset <P> --files <batch>` → 切片;读切片,摘要增补 timeline.md。
4. **通道二**:`scream-scan.py <batch>` → `findings/round-r-scream.md`。两通道**并列呈现,不合并**(R10):
   语义时间线可能因过滤漏掉证据,尖叫扫描是独立安全网。
5. **锚点 sanity check(三态)**——先按 R3 从现象**书面写出预期日志签名**(预期哪个 tag/包名/参数),再核对:
   - **三对齐命中**(时间±容差、包名/进程、参数都对上)→ 锚点确认,进 6。
   - **部分命中**(有相关特征但至少一项对不齐)→ 查 `clock-*.tsv`/静默区间能否解释偏差(开机校时、
     用户报时误差);能定位到**唯一可信命中行**→ 以它锚点校正回 2(不计策略切换,偏差入账);否则按下一档。
   - **完全无特征** → **先查 `loss-*.tsv`/静默区间确认不是日志丢失或 suspend 空洞(R13)**;再策略切换:
     `scream-scan`/grep 跨当前 session 全部文件搜预期签名。找到→重设锚点(记一次策略切换);
     未找到 / **策略切换累计≥2** / grep 命中与上次**同签名同位置** → 中断问用户(时间或描述可能有误)。
6. **语义匹配**:在 timeline_r 里找有效关键信息;未果回退 batch 原始文件限窗二次 grep。
7. **扩展判定**(**一切扩展/采样限定在锚点 session 内,R12**):
   - r ≥ {{MAX_ROUNDS}} 或 session 穷尽 → S6b;
   - profile=slow → 不做 ±2 扩展,改当前 session 等间隔采样(每 {{SAMPLE_STRIDE}} 文件)建趋势线找拐点;
   - 否则 r+=1,batch 两侧各扩 2 → 回双通道。
8. **explore 精定位**:锁定精确时间点后,`logcat-window.py` 抓 ±{{EXPLORE_WINDOW_SEC}} 秒窗;
   行数超 {{SLICE_LINE_CAP}} 先收紧 tag(加 --level 或缩 preset),**禁止扩窗**(R6)。产出交 S3。

每轮结束执行 ledger 轮次协议(references/ledger.md)。

## 避坑清单(环境类通用坑——cross-buffer 乱序等——见运行时 CLAUDE.md「已知坑」)
- **锚点时间是假设**:用户报的时间/现象是参考值不是 ground truth(R8),sanity check 就是为此设的。
- **不要无脑 ±2 扩展**:无特征时优先策略切换(全量搜签名),而不是盲目扩窗烧预算。
- **slow 剖面**(泄漏/累积):起因可能在症状前数十分钟,别只盯锚点附近,用采样建趋势线。
